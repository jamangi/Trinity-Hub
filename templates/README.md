# Gathering templates

These are proposed blank structures, not required workplace forms. Use them to organize permitted source material for SIFT. Actual work records stay in workplace systems; committed examples here must be synthetic.

- [Handoff](handoff.md): observations and chronology before interpretation.
- [Knowledge entry](knowledge-entry.md): shared structure for an error index, wiki, and Error Muncher.
- [Alias record](alias-record.md): command behavior before automation.
- [Isolation note](isolation-note.md): hypotheses and distinguishing evidence.

Use `unknown` when a value has not been established. Empty fields and illustrative placeholders are not operational facts. Adapt a workplace copy to local requirements rather than assuming these fields are sufficient.
