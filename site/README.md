# Trinity Hub field notebook

Open [index.html](index.html) locally, or use the GitHub Pages deployment. Keep index.html, styles.css, app.js and content.js together. No installation, network access, account or backend is required for local reading.

Notes includes a 47-page chronological narrative, eight reference topics, six incomplete process studies and a Traveler field map. Analysis contains 32 sourced interpretations, questions and proposals. Search covers the operational dataset. Source wording and uncertainty are available on each note page. Print this view prints the visible reading view in black and white; the separate gathering workbook is unchanged.

The source material and editing instructions live in [notes](../notes/README.md). Run `node scripts/build-notes.mjs` after editing its data. Run `node --test tests/*.test.mjs` and JavaScript syntax checks before publication.

GitHub Pages publishes only this directory through [.github/workflows/pages.yml](../.github/workflows/pages.yml). Repository-only content is excluded from the deployed artifact, but remains visible in a public repository. Do not add original photographs, credentials or live records here.
