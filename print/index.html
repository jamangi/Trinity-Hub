Workplace Learning Worksheets

Choose the sheets you need, print blank copies, and write answers by hand. Each topic can be reused with different people or on different days. Nothing is entered or saved in this page.

A gentle opener: “I’m learning how this works and trying to leave clearer notes. Could I ask you a couple of questions? Please feel free to correct anything I’ve misunderstood.” Ask the main question first; use the smaller prompts only when helpful.

Print setup: Letter or A4, portrait, 100% scale, one page per sheet, margins set to Default (the file supplies 0.5-inch margins). Turn off browser headers/footers and background graphics. Use the print dialog’s Copies field for repeat copies. Preview before printing; printer settings can vary.
